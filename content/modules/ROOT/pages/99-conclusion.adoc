== The technologies in detail

=== Quarkus

Quarkus is the cloud-native Java stack optimized for Kubernetes and OpenShift. Its advantages:

* **Dev Mode** with hot reload (Live Coding)
* **Dev Services**: automatic provisioning of dependencies in development
* **Ultra-fast startup**: seconds instead of minutes
* **Reduced memory footprint**: ideal for containers
* **Spring compatible**: progressive migration without full rewrite

Documentation: link:https://quarkus.io/guides/[quarkus.io/guides^]

=== Red Hat Developer Hub

Developer portal based on Backstage that centralizes:

* Pre-configured project templates (scaffolding)
* Component and API catalog
* CI/CD and deployment topology visualization
* Internal technical documentation

Documentation: link:https://developers.redhat.com/rhdh[developers.redhat.com/rhdh^]

=== Red Hat Trusted Application Pipelines

Product suite for software supply chain security:

* **Tekton / OpenShift Pipelines**: cloud-native CI/CD pipelines
* **Tekton Chains**: automatic image signing and SLSA attestations
* **Advanced Cluster Security (ACS)**: CVE scan, policies, compliance
* **Enterprise Contract**: policy-based provenance verification using Rego

Documentation: link:https://www.redhat.com/en/products/trusted-application-pipelines[redhat.com/trusted-application-pipelines^]

=== Red Hat OpenShift AI

MLOps platform integrated with OpenShift for:

* Training and fine-tuning ML/LLM models
* Model serving (OpenAI-compatible API)
* Model lifecycle management

Documentation: link:https://www.redhat.com/en/technologies/cloud-computing/openshift/openshift-ai[redhat.com/openshift-ai^]

=== Quarkus LangChain4j

Quarkus extension for LLM integration based on LangChain4j:

* `@RegisterAiService`: automatic LLM client generation
* `@SystemMessage` / `@UserMessage`: declarative prompts
* Support for OpenAI, Ollama, Hugging Face, and more
* Native integration with Micrometer for metrics

Documentation: link:https://docs.quarkiverse.io/quarkus-langchain4j/dev/[docs.quarkiverse.io/quarkus-langchain4j^]
